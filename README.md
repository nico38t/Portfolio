# Flask Portfolio

This is a single-page portfolio project built using Flask. The project showcases various experiences, projects, and contact information in a clean and modern design.

## Project Structure

```
flask-portfolio
├── app.py
├── requirements.txt
├── static
│   ├── css
│   │   └── style.css
│   └── images
├── templates
│   └── index.html
└── README.md
```

## Features

- **Responsive Design**: The portfolio is designed to be responsive and looks great on all devices.
- **Sections**: The portfolio includes sections for:
  - Header
  - Experience
  - Projects
  - Contact Information
- **Custom Styling**: The styles are derived from the previous project, ensuring a cohesive look and feel.

## Setup Instructions

1. **Clone the Repository**:
   ```
   git clone <repository-url>
   cd flask-portfolio
   ```

2. **Create a Virtual Environment** (optional but recommended):
   ```
   python -m venv venv
   source venv/bin/activate  # On Windows use `venv\Scripts\activate`
   ```

3. **Install Dependencies**:
   ```
   pip install -r requirements.txt
   ```

4. **Run the Application**:
   ```
   python app.py
   ```

5. **Access the Portfolio**:
   Open your web browser and go to `http://127.0.0.1:5000`.
