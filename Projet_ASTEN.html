Projet pour ASTEN - Générateur de Planning

Présentation du Projet

Ce projet est une application de génération automatique de plannings Excel développée pour automatiser la création de plannings de chantier à partir de fichiers DPGF (Devis). Ce projet vise à optimiser le processus de planification dans le secteur du BTP en proposant une solution moderne et intuitive.

Objectifs du Projet

  • Automatiser la génération de plannings Excel à partir de données DPGF.
  • Développer une interface utilisateur moderne et professionnelle.
  • Créer un exécutable autonome pour une distribution facile.
  • Optimiser les processus de planification dans le BTP.

Fonctionnalités Principales

  • Interface moderne et professionnelle avec configuration personnalisable
  • Durée de chantier personnalisable (1 à 52 semaines)
  • Date de début configurable avec validation automatique des lundis
  • Types de documents multiples : Planning prévisionnel et Rapport d'avancement
  • En-têtes de mois au-dessus des semaines pour une meilleure lisibilité
  • Weekends grisés et couleurs distinctes par feuille
  • Sauvegarde automatique dans le dossier Téléchargements
  • Aperçu des données avant génération

Technologies et outils utilisés

Technologies Détaillées

Le projet a été développé en utilisant les technologies suivantes :

  • Python 3.7+ : langage principal pour la logique applicative et le traitement des données.
  • Tkinter : interface graphique native pour une expérience utilisateur moderne et stable.
  • OpenPyXL : manipulation et génération de fichiers Excel avec formatage avancé.
  • PyInstaller : création d'exécutables autonomes pour une distribution simplifiée.
  • PIL (Pillow) : gestion des images et logos dans l'interface.

Architecture du Projet

Le projet suit une architecture modulaire bien structurée :

  1. main.py : point d'entrée principal de l'application
  2. ui_stable.py : interface utilisateur moderne et stable
  3. excel_parser.py : module de lecture et traitement des fichiers Excel
  4. planning_generator_v3.py : moteur de génération des plannings
  5. cEtude_generator.py : générateur d'études et de rapports
  6. build_all.bat : script de compilation automatisée

Processus de Développement

Le développement s'est organisé autour de plusieurs phases clés :

  1. Analyse des besoins : étude des processus de planification dans le BTP
  2. Conception de l'architecture : définition des modules et de leurs interactions
  3. Développement de l'interface : création d'une UI moderne avec Tkinter
  4. Implémentation des algorithmes : logique de génération des plannings
  5. Tests et optimisation : validation sur différents types de projets
  6. Packaging et distribution : création d'exécutables autonomes

Défis Techniques Relevés

Ce projet m'a permis de surmonter plusieurs défis techniques :

  • Gestion de la complexité : architecture modulaire pour un code maintenable
  • Interface utilisateur : création d'une UI moderne avec Tkinter natif
  • Formatage Excel avancé : gestion des styles, couleurs et mise en forme
  • Distribution d'application : création d'exécutables avec PyInstaller
  • Gestion des erreurs : robustesse et validation des données utilisateur

Résultats et Impact

Les principales réalisations du projet :

  • Application fonctionnelle : génération automatique de plannings professionnels
  • Interface intuitive : facilité d'utilisation pour les non-techniciens
  • Exécutable autonome : distribution simple sans installation Python
  • Gain de temps significatif : automatisation d'un processus manuel fastidieux
  • Code source documenté : architecture claire et maintenable

Compétences Développées

Ce projet m'a permis de développer et renforcer mes compétences en :

  • Développement Python avancé : POO, gestion des modules, architecture logicielle
  • Interface utilisateur : design moderne avec Tkinter, UX/UI
  • Manipulation de données : traitement Excel, validation, formatage
  • DevOps : automatisation du build, packaging d'applications
  • Gestion de projet : planification, versioning, documentation

Conclusion

Cette application représente une solution complète d'automatisation pour la génération de plannings de chantier. Cette solution permet d'automatiser efficacement la création de plannings professionnels à partir de données DPGF(Un Devis), en facilitant le travail des utilisateurs du secteur BTP. L'application propose une interface moderne, une génération rapide et fiable des documents, et contribue à améliorer la productivité en simplifiant un processus auparavant manuel et chronophage.
