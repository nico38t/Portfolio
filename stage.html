Rapport de Stage - Automatisation du Cycle de Vie des Comptes Utilisateurs

Présentation du Stage

Ce stage a été réalisé à la mairie d'Échirolles, dans le département informatique, avec pour objectif d’automatiser la gestion des comptes utilisateurs. L’enjeu principal était de synchroniser les comptes avec la base RH en utilisant LDAP Synchronization Connector (LSC).

Objectifs du Projet

  • Optimiser la gestion des comptes utilisateurs.
  • Mettre en place une synchronisation automatisée avec LDAP.
  • Développer une interface web pour la supervision des modifications.
  • Assurer une validation manuelle des changements avant application.

Technologies et partenaires

Technologies Utilisées

Le projet a été développé en utilisant les technologies suivantes :

  • Python : pour le scripting et la gestion des fichiers LDIF.
  • Flask : framework web permettant la création d'une interface de gestion.
  • LDAP Synchronization Connector (LSC) : pour la synchronisation des comptes.
  • Bootstrap : pour l’interface graphique responsive et ergonomique.

Déroulement du Projet

Le projet s'est déroulé en plusieurs phases :

  1. Analyse des besoins : compréhension des exigences et rédaction du cahier des charges.
  2. Développement des scripts : création des fichiers LDIF et mise en place de la logique de synchronisation.
  3. Développement de l'interface web : affichage des différences entre l’Active Directory et l’annuaire.
  4. Tests et validation : correction des incohérences et vérification du bon fonctionnement.

Compétences Acquises

Ce stage m’a permis de développer plusieurs compétences clés :

  • Développement web avec Flask et Bootstrap.
  • Gestion des fichiers LDIF et synchronisation LDAP.
  • Automatisation des processus informatiques.
  • Conception d’une architecture logicielle modulaire.

Résultats du Projet

Les principales réalisations sont :

  • Un système de synchronisation automatisée des comptes utilisateurs.
  • Une interface web intuitive pour valider et appliquer les changements.
  • Une réduction du temps de gestion des comptes et des risques d’erreurs.

Conclusion

Ce stage m'a offert une expérience concrète dans le domaine de l'automatisation informatique et la gestion des systèmes d'information. Il m’a permis de développer des compétences essentielles en programmation, architecture logicielle et administration des systèmes. L’interface web permet aujourd’hui une gestion optimisée des comptes utilisateurs et constitue une avancée notable pour la mairie d’Échirolles.
